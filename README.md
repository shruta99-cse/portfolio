# Shruti Sathe | Portfolio

🔗 **Live site:** [shruta99-cse.github.io/portfolio](https://shruta99-cse.github.io/portfolio/)

Personal portfolio built to showcase my projects, skills, and experience as a CSE student and full-stack developer.

## ✨ Features

- Interactive, animated UI with smooth scroll and transitions
- Sections for About, Skills, Projects, and Resume
- Responsive design across desktop and mobile
- Deployed on GitHub Pages

## 🛠️ Tech Stack

- **Framework:** React + Vite
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion, GSAP, Lenis (smooth scroll)
- **3D/Graphics:** Three.js, React Three Fiber, Drei
- **Icons:** Lucide React, React Icons
- **Deployment:** GitHub Pages via `gh-pages`

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/shruta99-cse/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run locally
npm run dev

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```
